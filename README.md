# Little things, always

A one-page scrapbook and love letter for Bhumika. Built with plain HTML, CSS, and JavaScript; no build step is required.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Personalize

- Replace the sample photos in `index.html` with the photos you want to use.
- Update the memory captions and note copy in `index.html` with your real shared stories.
- Adjust colors, spacing, and type in `styles.css`.

The Google Fonts and photo links currently load from their original hosted URLs, so those assets need internet access.
